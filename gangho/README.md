# 강호견문록 (江湖見聞錄) — 제1장 청풍문 편

텍스트 기반 무협 RPG 웹게임. 빌드 없이 `gangho/index.html`을 브라우저로 열면 바로 실행됩니다. 진행은 브라우저 `localStorage`에 저장됩니다.

## 구성
데이터·규칙·화면을 파일 단위로 나눴습니다. 한 기능을 고칠 때 다른 계층이 따라 깨지지 않게 하기 위해서입니다.

```text
index.html               화면 뼈대 + 스크립트 읽는 순서 (core → data → systems → ui → app)
admin.html               운영자 관리자 창 (core · data · systems · ui_admin만 읽음)
css/
  main.css               전체 레이아웃, 탭, 패널·카드, 강호행(탐험지·기록)·결산·관찰 창
  combat.css             전투 무대(관찰하기), 플로팅 대미지, 초식 현판
  effects.css            호버 발광, 셰이크, 섬광, 타자기, 현판·토스트
  admin.css              운영자 콘솔(GM) 전용 — 게임 화면과 섞이지 않는 독립 오버레이
js/
  core.js                공용 도구(난수·수치·조사) + 이벤트 버스(Bus, notify)
  data/                  [SSOT] 순수 정적 데이터. 함수·반복문 없음

    items.js             아이템·재료·소모품, 장비 기본형(티어별 능력치 표), 희귀도, 레시피 48종
    monsters.js          요수·두목 능력치와 고유 드랍 표, 피격 문구, 기척 지문
    maps.js              탐험 규칙(주기·누적·조우 가중치·귀환 조건), 요수 가중치, 금고 보상 풀, 함정, 구역, 기연 사건 표

  systems/               게임 규칙과 계산. DOM 조작 금지, 화면 상태(ui) 참조 금지
    stats_engine.js      능력치 합산(장비·비급·무신상·버프)
    growth_engine.js     경험치로 무공 성급 올리기, 소성·대성 돌파단, 경험치 획득 보정
    inventory_engine.js  행낭·무장·무공 장착, 소모 판정, 장비 강화, 전방 구매·판매
    combat_engine.js     전투 한 판을 끝까지 계산하고 합마다 기록(리플레이용), 명중·치명, 회피→반격, 자동 금창약, 전투력
    expedition_engine.js 한 시간 탐험: 조우(요수·금고·기연·함정·기관·두목), 결산, 최대 8번 누적·보관, 탐험지
    craft_engine.js      화로 기예, 도감 단서, 무신상 봉헌
    sect_engine.js       문파 임무, 인물(조운 안내·아린·장문인), 장경각, 하산

    ui_tabs.js           화면 상태(ui), 탭 전환, 상단 상태줄, 정청 아코디언, 전체 다시 그리기
    ui_logger.js         견문록: 최신 기록을 위에 붙이는 역순 로그
    ui_feedback.js       성취 현판, 토스트, 플로팅 대미지, 섬광·셰이크, 타자기
    ui_views.js          정청·화로·뒷마당·무신상·전방·무장·무공·행낭·도감 화면
    ui_field.js          강호행(탐험지·다음 출발·탐험 기록), 결산 창, 관찰하기(전투 리플레이)
    ui_modals.js         무공 상세·기연 사건·레시피·처음부터 다시·시작 화면 창
    ui_input.js          클릭·변경·키보드 → 시스템 함수 연결
    ui_admin.js          운영자 통합 디버그 콘솔 (GM_ENABLED로 켜고 끔)
  app.js                 초기화, 저장 상태 S와 런타임 상태 RT, 저장/불러오기, 저장 이전, 1초 틱
assets/                  무장 실루엣과 NPC 초상화. 없는 파일은 대체 그림으로 표시 (assets/README.md)
```

**계층 규칙**
- `data/`는 값만 담습니다. 레시피·비급서 아이템·장비 티어 능력치도 계산식 없이 표로 풀어 적었습니다.
- `systems/`는 상태 `S`·`RT`만 바꾸고, 화면에는 `notify.refresh()`·`notify.toast()`·`notify.banner()`·`notify.battle()`·`notify.view({ tab, modal, … })`·`notify.save()` 신호만 보냅니다. 화면 계층이 `Bus.on(...)`으로 받아 그립니다.
- `ui/`는 시스템 함수를 부르고 결과를 그립니다. 저장소에는 손대지 않습니다.
- `tests/check-layers.js`가 이 규칙을 정적으로 검사합니다: 데이터 파일의 로직, 시스템의 DOM 접근·화면 함수 호출·`ui` 참조, 스크립트 순서. `npm test`에 포함되어 있습니다.
- 모듈 번들러 없이 `file://`로 바로 열리도록 ES 모듈 대신 순서가 정해진 일반 스크립트를 씁니다.

## 구현된 시스템
- **탭 구조**: 1차 탭은 청풍문 · 상태 · 행낭 · 강호행 · 도감 다섯 개입니다. 좁은 화면에서도 한 줄에 모두 들어가 가로 스크롤이 없습니다.
- **청풍문(淸風門)**: 문파 시설을 2차 탭 [ 정청 ][ 화로 ][ 뒷마당 ][ 무신상 ][ 전방 ]으로 전환합니다. 들어올 때마다 정청부터 열립니다. 제자가 탐험을 다니는 동안에도 시설은 언제든 쓸 수 있습니다.
- **전투력(戰鬪力)**: 최대 활력 × 1 + 최대 내력 × 1.5 + 공격력 × 5 + 방어력 × 3 + 장착 무공 4종의 (등급 계수 × 현재 성 × 10)을 정수로 계산합니다. 능력치는 장비·무공·무신상·영약·음식 버프를 모두 합친 값입니다. 가중치는 `data/martial_arts.js`의 `CP_WEIGHTS` 한곳에 있습니다. 헤더의 은자 옆에 항상 작게 보이고, 바뀌면 ▲/▼ 변화량이 잠깐 붙습니다. 상태 탭 맨 위에는 전투력 카드(체력·내력 / 공격·방어 / 무공 내역)가 있습니다. 엔진은 `calculateCombatPower(S)`로 늘 새로 계산하고, 저장 상태의 `S.combatPower`는 refresh 신호와 1초 틱마다 맞추는 거울 값입니다. 적 조우 때 뜨는 기척 지문은 난이도 판정을 바꾸지 않도록 기존 비교식을 그대로 씁니다.
- **상태(狀態)**: 2차 탭 [ 무장 ] / [ 무공 ]. 무장은 착용 장비 슬롯·강화·능력치, 무공은 장착 중인 4대 무공·익힌 무공·보유 비급([ 익히기 ])입니다. 마지막에 본 하위 탭을 기억합니다.
- **전방(廛房)**: 청풍문 전속 객주 '청풍전방 왕 가'. [ 구매 ]에서 금창약·소환단·주먹밥·기본 재료와 하품 기본 장비(무기 5종·호갑·두건·짚신)를 은자로 사고, [ 판매 ]에서 행낭 소지품(한 개 / 전부)과 보관 장비를 즉시 은자로 바꿉니다. 장비 되팔기 값은 티어·희귀도·강화 단계로 정해집니다. 비급·증표·신분패·탈것은 사고팔 수 없습니다. 은자가 모자라면 구매가 막히고 견문록에 사유가 남습니다.
- **행낭(行囊)**: 보관 장비(착용·버리기)와 소지품 목록, 종류별 분류.
- **무공**: 시작하면 입문 무공 비급 1권과 토납법·포철삭·철포삼 비급이 행낭에 들어옵니다. 상태 › 무공(또는 행낭)에서 [ 익히기 ]로 익히고, 상태 › 무공에서 무공·심법·경공·기공 슬롯에 장착하거나 해제합니다. 익힌 무공 카드를 누르면 등급, 성, 설명, 장착 보너스, 초식, 성급 올리기, 장착하기/장착 해제 버튼이 있는 창이 뜹니다. 장경각에서 교환한 비급도 행낭으로 들어옵니다.
- **성장 (경험치)**: 연무장과 비급별 수련·실전 경험치는 없습니다. 탐험에서 적을 쓰러뜨리면 경험치(經)가 하나의 주머니에 모이고, 상태 › 무공에서 원하는 무공에 써서 성급을 올립니다(`STAR_EXP`: 1→2성 60 … 11→12성 1,200, 등급 계수를 곱함). 5→6성(소성)에는 소성 돌파단, 11→12성(대성)에는 대성 돌파단이 함께 듭니다. 신분패·산채밥·청심정기단의 '경험치 획득' 보정이 곱해집니다.
- **견문록**: 넓은 화면에서는 왼쪽 본문과 같은 높이로 고정되고 최신 기록이 맨 위에 쌓입니다. 아이템명·은자·공헌도는 색으로 강조됩니다.
- **화면**: 먹빛 다크 테마입니다. UI·수치는 Noto Sans KR, 지문·전투 로그·대사는 Noto Serif KR로 씁니다. 메뉴 이름은 한글을 크게, 한자를 작게 붙입니다.
- **무신상**: 독립 탭입니다. 기예 실패 부산물을 봉헌해 영구 능력치를 얻습니다.
- **화로**: 주조·연단·조리, 최대 10칸 투입. 모든 재료에 `craftType`(forge/alchemy/cooking)이 있어 고른 기예의 재료만 보이고, 레시피도 한 분류 재료로만 만듭니다. 성공률 대신 숙련에 따라 불길 지문이 바뀝니다. 레시피는 48종입니다.
- **뒷마당**: 평상 휴식(활력·내력은 항상, 기력은 5분 간격으로 전부 회복), 음식·영약 먹기, 아린(일일 약과, 이야기 나누기).
- **정청**: 노벽송(장문인)이 지금 할 일 하나만 순차로 알려 줍니다. 조운(대사형)은 문파 안내 전담입니다. [ 문파 안내 ]를 누르면 지금 상황(안 익힌 비급, 빈 무공 슬롯, 정하지 않은 탐험지, 쓸 수 있는 경험치, 금창약 부족, 완료 가능한 임무 등)을 보고 다음 할 일을 짚어 주고, 하루 한 번 보급품을 줍니다. 물건 매매는 전방에서 합니다. 문파 임무로 문파 공헌도를 벌고, 장경각에서 청풍문 세트(청풍권·검·도·창·표, 청풍심법·경공·기공, 신분패)와 바꿉니다.
- **상태 › 무장**: 중앙 실루엣 이미지 둘레에 투구·무기·호갑·옥패, 하단 가로줄에 신발·요대·가락지·신분패·탈것. 행낭 기본 100칸.
- **도감**: 레시피 해금 그리드. 조합에 성공하면 그 조합에 쓴 재료마다 '이 재료가 들어가는 다른 조합식'이 단서 칸으로 드러납니다. 단서 칸에는 완성품과 아는 재료만 보이고 나머지는 가려져 있어, 유저끼리 정보를 나누며 채워 가게 됩니다. 화로 제작에 성공하거나 아린·장문인에게 들으면 영구 해금됩니다. 해금된 칸을 누르면 완성품 능력치, 필요 재료, 화로 채우기 버튼이 있는 창이 뜹니다.
- **강호행 (자동 탐험)**: 지도는 없습니다. 유저는 탐험지만 고르고, 제자가 **한 시간마다** 스스로 나가 **기력을 다 쓸 때까지** 조우를 겪고 돌아옵니다.
  - 구역: 청풍산 → 염화채 → 적룡방. 두목을 쓰러뜨리면 다음 구역이 열립니다. 탐험지를 처음 고르면 첫 탐험은 곧바로 떠납니다.
  - 한 걸음마다 요수(전투) 60 · 금고 20 · 함정 7 · 기관 7 · 기연 6 가중치로 조우합니다(기연은 탐험 한 번에 한 번). 기력을 60% 넘게 쓴 뒤에는 두목과 마주칠 수 있는데, 기척이 너무 무거우면 제자가 알아서 피합니다. 요수는 후반일수록 중형이 잦습니다.
  - 출발할 때 활력·내력은 가득 찹니다. 활력이 35% 아래로 떨어지면 금창약을 알아서 먹고, 이길 때마다 숨을 고르며 8%를 되찾습니다. 금창약도 없이 활력이 30% 아래면 벌칙 없이 스스로 발길을 돌리고, 쓰러지면 이번에 번 은자의 절반을 잃고 활력 10%로 돌아옵니다.
  - 기력은 한 시간에 걸쳐 다시 찹니다. 음식의 기력은 최대치를 넘어(두 배까지) 쌓여 다음 탐험을 길게 만들고, 음식·영단 효과는 다음 탐험 한 번 동안 적용됩니다.
  - **누적과 보관**: 자리를 비운 동안의 탐험은 최대 8번까지만 쌓였다가 돌아오면 한꺼번에 결산 창으로 보여 줍니다(그보다 오래 비우면 오래된 기회부터 지나갑니다). 탐험 기록도 최근 8번만 남기고 오래된 것부터 지웁니다.
  - **견문록**: 탐험마다 요약 한 줄과 걸음마다 한 줄씩 남깁니다. 전투에는 `[관찰하기]`가 붙어, 누르면 그 전투만 합 단위로 다시 재생합니다(멈춤·1×/2×/4×·끝까지). 전투 대사는 견문록이 아니라 관찰 창에만 나옵니다.
  - 강호행 탭에는 탐험지 카드, 다음 출발 카운트다운, 탐험 기록(펼치면 걸음과 관찰하기)이 있습니다.
- **기연(奇緣)**: 지역마다 고유 사건 4종과 공용 2종. 제자가 조건(아이템·은자·기력·능력치·무공 성급)을 채운 선택지 중 하나를 스스로 고르고, 확률로 보상·손해·전투가 갈립니다.
- **은자 사용처**: 청풍문 › 전방(구매·판매), 무장 화면의 장비 강화(+1마다 기본 능력치 10%, 최대 +10, 실패해도 등급 유지).
- **자동 전투**: 한 판을 끝까지 계산하며(속도가 빠른 쪽이 먼저), 합마다 대사·연출·양쪽 활력을 기록해 관찰하기로 다시 봅니다. 적의 공격은 회피 → (실패 시) 피격 → 반격 스탯 확률로 【반격】 순서로 판정하며, 회피에 성공하면 반격은 없습니다.
- **드랍**: 적마다 고유 드랍 테이블만 판정합니다(들토끼: 토끼고기·토끼가죽, 들개: 들개 이빨·거친 가죽, 멧돼지: 멧돼지고기·송곳니·두꺼운 가죽, 외눈 멧돼지왕: 왕의 송곳니·흑철·불씨석).
- **경계(2단계)**: 1~5성 입문(入門), 5→6성에 소성 돌파단을 더해 6성 소성(小成)(장착 능력치 30%·초식 위력 25% 상향), 11→12성에 대성 돌파단을 더해 12성 대성(大成 / 極意)에 이르고 분류별 극의 패시브가 열립니다.
- **연출**: 피해 숫자는 일반 적중이 주황·적색, 치명타가 1.5배 크기의 굵은 금색(떨림), 회피가 청록색 `회피!`로 솟구칩니다. 적중할 때마다 인장에 0.1초 섬광(적은 흰빛, 내가 맞으면 붉은빛)이 스치고, 치명타나 최대 활력 20% 이상의 강타에는 0.15초 잔떨림(`@keyframes shake`)이 붙습니다. 이 연출은 관찰하기 창에서 합마다 재생됩니다. 장문인·대사형·사매·왕 가의 첫 대사는 한 글자씩 찍히며, 아무 곳이나 누르면 전체가 바로 보입니다. 움직임 줄이기 설정에서는 모두 생략됩니다.

## 운영자 콘솔 (GM)
개발·테스트용입니다. 두 가지로 띄울 수 있고, 화면과 기능은 같습니다.

- **게임 안 오버레이**: 화면 우측 하단 `[GM]` 버튼이나 `F1` / `` ` `` / `~` 키로 여닫습니다(입력칸에 글자를 치는 중에는 `` ` ``·`~`를 무시). `Esc`나 바깥을 누르면 닫힙니다. 휴대폰 테스트에 편합니다.
- **별도 관리자 창 (`admin.html`)**: 오버레이 머리의 `[새 창 ↗]`을 누르거나, 게임과 같은 폴더의 `admin.html`을 직접 엽니다. 두 번째 모니터에 띄워 두고 게임하면서 보기 좋습니다.
  - 게임 창과 `BroadcastChannel`로 이어집니다. 게임이 1초마다 저장 상태 `S`와 전투 요약, 추적 기록을 보내고, 관리자 창은 [적용]·소환·재료 지급·치트를 **명령**으로 보내 게임 쪽에서 실행합니다.
  - 관리자 창은 `core.js`·`data/`·`systems/`만 읽어 받은 복사본으로 같은 계산(능력치 등)을 합니다. 화면 계층과 `app.js`는 읽지 않습니다.
  - 게임을 새로고침·초기화해도 관리자 창과 추적 기록은 남고 자동으로 다시 이어집니다. 게임 창이 없으면 머리에 '게임 창을 기다리는 중'이 뜹니다.
  - 같은 출처에서 열어야 합니다(같은 폴더·같은 사이트). 로컬 파일로 열 때 크롬 계열은 되지만, 파일마다 출처를 따로 보는 브라우저(파이어폭스 등)에서는 이어지지 않을 수 있습니다. 팝업이 막히면 `admin.html`을 직접 여십시오.

| 탭 | 기능 |
| --- | --- |
| 유저 상태 | 활력·내력·기력·은자·공헌도·경험치·탐험지·다음 출발, 장착 무공 4종의 ID·성·경험치, 행낭, 저장 상태 `S` 원시 JSON을 1초마다 갱신. 은자·활력·내력·기력·공헌도를 입력해 [적용] (최대치로 제한) |
| 행동 추적 | 탭 전환·화면 전환·클릭·전투 조우/승패·아이템 획득/소모·알림·경고(재화 부족 등)·예외를 밀리초 시각과 함께 기록. 최신이 위, 최대 300줄, 견문록과 별개, [로그 비우기] |
| 아이템 DB | 전체 아이템 표(ID·이름·분류·가치·보유), 검색·분류 거르기, [+1 소환] [+10 소환] |
| 조합법 | 레시피 48종의 재료·결과·도감 해금 여부, 기예별 거르기, [필요 재료 지급] |
| 쾌속 치트 | [은자 +1,000냥], [경험치 +1,000], [활력/내력 100% 회복], [기력 가득], [탐험 즉시 1회], [1시간 경과](예약된 탐험을 실제 결산 경로로), [10시간 경과](8번까지만 쌓이는지 확인), [데이터 완전 초기화](두 번 눌러 확인) |

- 값 주입은 기존 시스템 함수(`give`, `advance`, `clampVitals`, `doReset` …)를 그대로 불러 게임 상태·화면과 어긋나지 않습니다.
- 행동 추적은 시스템이 보내는 `notify.trace` 신호와 화면 계층의 신호(Bus)로 모읍니다. 시스템이 콘솔을 직접 알지 못하게 해 계층 규칙을 지킵니다.
- 출시할 때는 `js/ui/ui_admin.js` 맨 위의 `GM_ENABLED`를 `false`로 바꾸고(버튼·단축키·창 연결이 모두 꺼짐), `admin.html`을 배포에서 빼십시오.

```bash
cd gangho
npm install          # playwright 설치 (처음 한 번)

node tests/run-all.js round10  # 이름에 round10이 들어간 묶음만
```
