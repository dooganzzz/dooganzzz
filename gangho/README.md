# 강호견문록 (江湖見聞錄) — 제1장 청풍문 편

텍스트 기반 무협 RPG 웹게임. 빌드 없이 `gangho/index.html`을 브라우저로 열면 바로 실행됩니다. 진행은 브라우저 `localStorage`에 저장됩니다.

## 구성
- `index.html` — 화면 뼈대
- `css/style.css` — 한지(라이트) / 먹(다크) 테마
- `js/data.js` — 비급, 아이템, 블라인드 레시피, 장비, 적, 구역 지도 데이터
- `js/game.js` — 게임 로직(수련·전투·기예·탐험·NPC)과 렌더링
- `assets/` — 무장 실루엣과 NPC 초상화. 없는 파일은 대체 그림으로 표시됩니다 (`assets/README.md` 참고)

## 구현된 시스템
- **탭 순서**: 정청 · 무공 · 연무장 · 화로 · 뒷마당 · 무장 · 강호행 · 무신상 · 도감
- **무공**: 시작하면 입문 무공 비급 1권과 토납법·포철삭·철포삼 비급이 행낭에 들어옵니다. 행낭에서 [ 익히기 ]로 익히고, 무공 탭에서 무공·심법·경공·기공 슬롯에 장착하거나 해제합니다. 익힌 무공 카드를 누르면 등급, 성과 숙련도, 설명, 장착 보너스, 초식, 장착하기/장착 해제 버튼이 있는 창이 뜹니다. 장착한 무공만 연무장에서 수련할 수 있고, 장경각에서 교환한 비급도 행낭으로 들어옵니다.
- **견문록**: 넓은 화면에서는 왼쪽 본문과 같은 높이로 고정되고 새 기록이 오면 맨 아래로 스크롤됩니다. 아이템명·은자·공헌도는 색으로 강조됩니다.
- **화면**: 먹빛 다크 테마입니다. UI·수치는 Noto Sans KR, 지문·전투 로그·대사는 Noto Serif KR로 씁니다. 메뉴 이름은 한글을 크게, 한자를 작게 붙입니다.
- **연무장**: 처음엔 수련 정지 상태입니다. 카드마다 [ 수련하기 ]/[ 수련 중지 ]가 있고, 한 번에 한 비급(`activeTrainingSkillId`)만 수련 경험치가 쌓입니다. 기본 효율로 입문→소관문 4시간, 소관문→중관문 8시간, 중관문→대관문 24시간이 걸리고, 신분패·음식이 이를 줄입니다. 수련만 먼저 해 둬도 다음 관문까지의 몫은 버려지지 않습니다. 오프라인 수련은 최대 24시간까지 쌓입니다. 카드를 누르면 초식, 관문, 이월 경험치 상세가 뜹니다.
- **무신상**: 독립 탭입니다. 기예 실패 부산물을 봉헌해 영구 능력치를 얻습니다.
- **화로**: 주조·연단·조리, 최대 10칸 투입. 모든 재료에 `craftType`(forge/alchemy/cooking)이 있어 고른 기예의 재료만 보이고, 레시피도 한 분류 재료로만 만듭니다. 성공률 대신 숙련에 따라 불길 지문이 바뀝니다. 레시피는 48종입니다.
- **뒷마당**: 평상 휴식(활력·내력은 항상, 기력은 5분 간격으로 전부 회복), 음식·영약 먹기, 아린(일일 약과, 이야기 나누기).
- **정청**: 노벽송(장문인)이 지금 할 일 하나만 순차로 알려 줍니다. 조운(대사형)은 하루 한 번 보급품을 줍니다. 문파 임무로 문파 공헌도를 벌고, 장경각에서 청풍문 세트(청풍권·검·도·창·표, 청풍심법·경공·기공, 신분패)와 바꿉니다.
- **무장·행낭**: 중앙 실루엣 이미지 둘레에 투구·무기·호갑·옥패, 하단 가로줄에 신발·요대·가락지·신분패·탈것. 행낭 기본 100칸.
- **도감**: 레시피 해금 그리드. 조합에 성공하면 그 조합에 쓴 재료마다 '이 재료가 들어가는 다른 조합식'이 단서 칸으로 드러납니다. 단서 칸에는 완성품과 아는 재료만 보이고 나머지는 가려져 있어, 유저끼리 정보를 나누며 채워 가게 됩니다. 화로 제작에 성공하거나 아린·장문인에게 들으면 영구 해금됩니다. 해금된 칸을 누르면 완성품 능력치, 필요 재료, 화로 채우기 버튼이 있는 창이 뜹니다.
- **강호행**: 사냥터는 12×10 격자로 입장할 때마다 새로 생성됩니다. 입구는 좌측 하단, 두목은 우측 상단 끝이며 BFS로 모든 칸이 이어집니다. 일반 몹 6~8, 중형 3~4(깊은 곳), 약초·광맥 각 3~5, 상자 1~2(막다른 길), 기연 1이고 이벤트끼리는 붙지 않습니다. 나머지는 모두 산길(약 70%)입니다. 아직 열리지 않은 지역은 화면에 나오지 않습니다.
- **강호행(공통)**: 청풍산 → 염화채 → 적룡방 순서로, 두목을 꺾으면 다음 지역이 열립니다. 지도는 시작할 때 BFS로 입구에서 모든 노드(두목 포함)까지 이어지는지 검사하고, 끊긴 곳은 산길로 잇습니다. 기믹은 길을 막지 않고 보상을 줍니다. 적 수치는 숨기고 기척 지문 5단계로 알려 줍니다. 자동 회복은 없습니다. 토벌·채집·채광·상자·기믹을 마친 노드는 산길이 되고, 청풍문에 돌아갔다 다시 들어가야 지도 전체가 재배치됩니다.
- **실전 경험치**: 전투 1회 승리마다 장착한 비급에 각각 +1. 성당 필요 승리 수는 입문 구간 10회, 소관문 이후 20회, 중관문 이후 40회입니다(관문까지 30/80/160승).
- **자동 공격**: 일반 몹 전투에서는 [ 자동 공격 ]으로 끝까지 몰아칠 수 있고, 활력이 25% 아래로 떨어지면 멈춥니다. 두목전은 매 턴 직접 고릅니다.
- **은자 사용처**: 정청의 조운의 창고(소모품·재료 구매), 무장 화면의 장비 강화(+1마다 기본 능력치 10%, 최대 +10, 실패해도 등급 유지).
- **턴제 전투**: 매 턴 공격·방어·도주를 고릅니다. 공격은 확률로 1→2(4성)→3(8성)초식이 이어집니다. 방어는 받는 피해를 50~70% 줄이고, 반격 확률만큼 적의 공격을 흘려낸 뒤 반격합니다.
- **성장**: 1~12성, 실전 100% + 수련 100%가 모두 차야 오르고 넘친 경험치는 이월됩니다. 3·7·11성 관문은 돌파단을 복용해 넘습니다.

## 검사
브라우저 자동 검사(Playwright)가 `tests/`에 있습니다. 데스크톱(1280px)과 폰(390px) 폭에서 게임 규칙과 화면을 확인합니다.

```bash
cd gangho
npm install          # playwright 설치 (처음 한 번)
npm test             # 전체 검사, 실패가 있으면 종료 코드 1
node tests/run-all.js round7   # 이름에 round7이 들어간 묶음만
```
