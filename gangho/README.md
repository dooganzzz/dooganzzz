# 강호견문록 (江湖見聞錄) — 제1장 청풍문 편

텍스트 기반 무협 RPG 웹게임. 빌드 없이 `gangho/index.html`을 브라우저로 열면 바로 실행됩니다. 진행은 브라우저 `localStorage`에 저장됩니다.

## 구성
- `index.html` — 화면 뼈대
- `css/style.css` — 한지(라이트) / 먹(다크) 테마
- `js/data.js` — 비급, 아이템, 블라인드 레시피, 장비, 적, 구역 지도 데이터
- `js/game.js` — 게임 로직(수련·전투·기예·탐험·NPC)과 렌더링

## 구현된 시스템
- **4대 방치 수련**: 무공·심법·경공·기공. 1~12성, 3→4 / 7→8 / 11→12성은 관문으로 하급·중급·상급 돌파단이 필요합니다. 오프라인 수련은 최대 8시간까지 쌓입니다. 강호행 중에는 효율이 절반입니다.
- **듀얼 경험치**: 실전 100% + 수련 100%를 모두 채워야 성이 오르고, 넘친 경험치는 다음 성으로 이월됩니다.
- **초식 콤보 전투**: 속도 기반 턴제. 내력을 써서 1초식 → 2초식(4성) → 3초식(8성)이 확률적으로 이어집니다. 무공과 병기 종류가 맞아야 초식이 나갑니다. 피해 비율에 따라 5단계 피격 묘사가 나옵니다.
- **8방향 노드 탐험**: 청풍산, 염화채, 적룡방. 걷는 데는 기력이 들지 않고, 전투·채집·보물상자·기믹·두목에는 기력이 듭니다.
- **블라인드 기예**: 주조·연단·조리, 레시피 48종. 성공한 조합은 도감에 기록되고, 실패하면 부산물이 남습니다. 부산물은 무명 무신상에 봉헌해 영구 능력치로 바꿉니다.
- **장비 9슬롯**과 하품~극품 희귀도. 제작 장비에는 고유 옵션이 붙습니다.
- **NPC**: 노벽송(돌파·비급·하산), 조운(도구·위험도·탈것·매입), 아린(간식·레시피 귀띔·물물교환). 문파 임무도 있습니다.
