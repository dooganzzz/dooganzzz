# 강호견문록 (江湖見聞錄) — 제1장 청풍문 편

텍스트 기반 무협 RPG 웹게임. 빌드 없이 `gangho/index.html`을 브라우저로 열면 바로 실행됩니다. 진행은 브라우저 `localStorage`에 저장됩니다.

## 구성
데이터·규칙·화면을 파일 단위로 나눴습니다. 한 기능을 고칠 때 다른 계층이 따라 깨지지 않게 하기 위해서입니다.

**계층 규칙**
- `data/`는 값만 담습니다. 레시피·비급서 아이템·장비 티어 능력치도 계산식 없이 표로 풀어 적었습니다.
- `systems/`는 상태 `S`·`RT`만 바꾸고, 화면에는 `notify.refresh()`·`notify.toast()`·`notify.banner()`·`notify.battle()`·`notify.view({ tab, modal, … })`·`notify.save()` 신호만 보냅니다. 화면 계층이 `Bus.on(...)`으로 받아 그립니다.
- `ui/`는 시스템 함수를 부르고 결과를 그립니다. 저장소에는 손대지 않습니다.
- `tests/check-layers.js`가 이 규칙을 정적으로 검사합니다: 데이터 파일의 로직, 시스템의 DOM 접근·화면 함수 호출·`ui` 참조, 스크립트 순서. `npm test`에 포함되어 있습니다.
- 모듈 번들러 없이 `file://`로 바로 열리도록 ES 모듈 대신 순서가 정해진 일반 스크립트를 씁니다.

## 세계관과 시작
- **프롤로그**: 무협 소설 《강호견문록》을 읽다 잠든 '나'는 소설 속 몰락 문파 청풍문의 **무신상(석상)**에 빙의합니다. 움직일 수 없는 나 대신, 목소리가 닿는 풋내기 제자 하나가 강호를 걷습니다. 유저는 석상으로서 제자를 준비시키고 지켜봅니다.
- **제자 만들기**: 이름, **4대 기본 스탯**, 입문 무공 1종, **기예(技藝)** 1종을 고릅니다.
  - 4대 스탯: 합계 24, 한 스탯 3~10 (기본 6/6/6/6). 근력·체력·지력은 기준 6에서 한 점마다 **근력** 공격력 +2·적재량 +6, **체력** 최대 활력 +12·방어 +0.8, **지력** 최대 내력 +6·오행 극 위력 +2%p. **민첩**은 수치 그대로 회피율 민첩×0.5% · 치명타율 민첩×0.4% · 탐험 기력 소모 민첩×1% 감소, 선공은 '속도 + 민첩'과 요수의 속도를 비교합니다. 전투력에 민첩×8이 더해집니다.
  - 기예: **단조**(장비 제작 · 제련 특화 — 단조 성공률 +10% · 단조 실패 시 찌꺼기 2배) / **단약**(영약 제조 · 연단 특화 — 단약 성공률 +10% · 단약 섭취 효과 +15%). 단조·단약 솜씨는 모두 9품에서 시작해 1품까지 오릅니다.

## 3대 상성
상성 값은 모두 `data/martial_arts.js`의 `ELEMENTS`·`ELEM_BEATS`·`TERRAINS`·`WEAPON_ADV`·`AFFINITY`에 있습니다.
- **지형 × 경공 (기력)**: 5대 지형 풀(草)·물(水)·흙(土)·나무(木)·일반(平). 구역마다 지형이 하나 이상입니다(청풍산 = 흙/풀/나무, 염화채 = 흙/일반, 수룡방 = 물/일반). 장착 경공의 지형이 구역 지형 중 **하나라도** 맞으면 그 탐험의 기력 소모 -20%, 하나도 안 맞으면 +20%(경공이 없으면 보정 없음). 경공: 초상비 풀 · 답수보 물 · 지행보 흙 · 등수보 나무 · 미종보 일반 (포철삭 흙 · 청풍경공 일반). 구역 카드에 지형이 보이고, 출정 준비의 상성 줄이 일치 여부를 알려 주며, 탐험 기록에 "지형 … · 경공 … 일치 (기력 n 아낌)"이 남습니다.
- **오행 × 기공 (피해)**: 적마다 고유 오행이 있고 장착 기공에 오행이 있습니다(철포삼 金, 청풍기공 木, 열화기공 火, 수류기공 水, 황토기공 土). 목극토·토극수·수극화·화극금·금극목. 내가 극하면 주는 피해 +25%(지력 보정 추가)·받는 피해 -25%, 극당하면 반대입니다. 상생은 보정 없음.
- **병기 가위바위보**: 권장 › 검/도, 창 › 권장, 검/도 › 창·암기, 암기 › 권장, 창 = 암기 (검과 도는 같은 계열). 우세하면 공격력 +15%·명중 +10%p, 열세하면 주는 피해 -15%이고 상대가 그만큼 유리합니다. 요수도 병기 계열이 있습니다(살쾡이 발톱 = 권장, 멧돼지 엄니 = 창, 독사 독니 = 암기 등).
- 오행 기공: 목령진기 木 · 벽화공 火 · 후토공 土 · 백금결 金 · 유수심법 水 (철포삼 金 · 청풍기공 木).
- 전투 기록(관찰 창) 첫머리에 `☯ 상성 — 오행 … · 병기 …` 한 줄과 기공 지문이 남고, 강호행의 출정 준비에도 내 기공 오행·경공 지형·병기 계열이 보입니다. 적의 오행·병기는 한 번 만나 본 뒤에야 요수 도감에 드러납니다.

## 전투 묘사 (3단계)
관찰 창의 전투 기록은 한 번의 공격을 세 줄로 합성합니다. 템플릿은 `data/skills.js`의 각 무공 `stances`와 `STANCE_DEFAULT`, 요수의 `atkText`에 있습니다.
1. **초식 선언** `【 무공명 - 초식명 !! 】` (`.log-stance-title`, 금색 굵게) — 초식이 발동했을 때와 반격.
2. **기세·호흡** 지문 (`.log-stance-desc`, 기울임) — 예: "{제자}가 호흡을 깊이 들이마신 뒤 {병기}를 굳게 쥐고 벼락같이 내려친다!". `{attacker}{이가}`처럼 받침에 맞춰 조사를 붙입니다.
3. **타격·후폭풍** (`.log-stance-result`, 피해는 붉은색) — 일반타는 피격 반응 + `(-피해)`, 치명타는 "회심의 일격! 급소를 정확히 꿰뚫었다!", 빗나가면 "(빗나감)".
- 병기 상성 우위면 한 턴에 한 번 `[상성 우위] 병기의 이점을 살린 궤적이 적의 빈틈을 파고든다!`가 끼어듭니다.
- 적의 공격도 공격 지문 → 결과(회피 시 장착 경공의 보법 지문)로 나오고, 전투 시작에는 장착 기공의 지문이 흐릅니다. 평타는 지문 + 결과 두 줄입니다.

## 무공 · 요수 · 장비 DB
- **삼류 무공 25종** (`data/skills.js`, 무신상 공양 비급·금고의 비급 궤에서): 권장 파석권·쇄골장·연환통배권 / 검 청풍검법·낙엽검법·추풍검 / 도 오호단문도·벽력도법·단수도 / 창 육합창법·철기창·풍운점혈창 / 암기 비연표·산화철질려·투골정 / 경공 5대 지형 / 기공 오행 5종. 무공마다 3초식 이름과 지문, 작은 고유 능력치(`extra`)가 있습니다.

## 구현된 시스템
- **탭 구조**: 1차 탭은 청풍문 · 상태 · 행낭 · 강호행 · 견문록 · 도감 여섯 개입니다. 좁은 화면에서도 한 줄에 모두 들어가 가로 스크롤이 없습니다.

- **전투력(戰鬪力)**: 최대 활력 × 1 + 최대 내력 × 1.5 + 공격력 × 5 + 방어력 × 3 + 장착 무공 4종의 (등급 계수 × 현재 성 × 10)을 정수로 계산합니다. 능력치는 장비·무공·무신상·단약 버프를 모두 합친 값입니다. 가중치는 `data/martial_arts.js`의 `CP_WEIGHTS` 한곳에 있습니다. 헤더는 왼쪽에 캐릭터 정보(1행)와 활력·내력 게이지 + [전투력] · [수련치] · [은자] · [공헌] 칩(2행), 오른쪽 끝에 강호견문록 배너가 있고(폰에서는 배너가 맨 위 오른쪽, 캐릭터 정보가 그 아래 한 줄 전체), 전투력이 바뀌면 ▲/▼ 변화량이 잠깐 붙습니다. 상태 탭 맨 위에는 전투력 카드(체력·내력 / 공격·방어 / 무공 내역)가 있습니다. 엔진은 `calculateCombatPower(S)`로 늘 새로 계산하고, 저장 상태의 `S.combatPower`는 refresh 신호와 1초 틱마다 맞추는 거울 값입니다. 적 조우 때 뜨는 기척 지문은 난이도 판정을 바꾸지 않도록 기존 비교식을 그대로 씁니다.
- **상태(狀態)**: 2차 탭 [ 무장 ] / [ 무공 ]. 무장의 장비 칸을 누르면 그 부위의 행낭 장비 목록 창이 떠 장착·교체·해제·강화를 하고, 무공의 4대 칸을 누르면 그 계열의 익힌 무공 목록 창이 떠 장착·교체·해제·상세를 합니다. 정청의 접이 칸(정청 본부·문파 임무·장경각)은 모두 접힌 채로 시작합니다. 무장은 착용 장비 슬롯·강화·능력치, 무공은 장착 중인 4대 무공·익힌 무공·보유 비급([ 익히기 ])입니다. 마지막에 본 하위 탭을 기억합니다. 무장 화면 가운데에는 3:4 **제자 일러스트 카드**(`assets/images/character_default.png`, 없으면 먹빛 SVG 플레이스홀더)와 `청풍문 제자 (이름)` 이름표가 있습니다. 무공 장착 칸은 가운데 크게 놓인 운기조식 가부좌(지름 320px, 단전에 기운이 모이는 SVG) 둘레에 12시 심법 · 9시 무공 · 3시 기공 · 6시 경공 컴팩트 카드(140px)로 둘러 배치됩니다. 좌선과 네 방위를 잇는 먹선 기운 순환 궤적이 깔리고, 카드는 수묵 테두리(대각 곡률)와 미세한 위치·기울기 편차로 십자 대칭을 살짝 흐트러뜨립니다. 무장 칸도 몸의 곡선을 따라 조금씩 들여 씁니다.

[ 구매 ]에서 생혈고·소환단·청풍산 재료와 하급 장비(무기 5종·가죽옷·도포·가락지·허리띠·옥대)와 기본 두건·짚신을 은자로 사고, [ 판매 ]에서 행낭 소지품(한 개 / 전부)과 보관 장비를 즉시 은자로 바꿉니다. 장비 되팔기 값은 티어·희귀도·강화 단계로 정해집니다. 비급·증표·신분패·탈것은 사고팔 수 없습니다. 은자가 모자라면 구매가 막히고 견문록에 사유가 남습니다. 판매·휴식 앞에는 재확인 창(`showConfirmModal`)이 뜹니다. 신분패: 제자패 +10% · 정식제자패 +5% · 내문제자패 +10% (수련치 획득).

- **기연(奇緣)**: 지역마다 고유 사건 4종과 공용 2종. 제자가 조건(아이템·은자·기력·능력치·무공 성급)을 채운 선택지 중 하나를 스스로 고르고, 확률로 보상·손해·전투가 갈립니다.
- **은자 사용처**: 청풍문 › 전방(구매·판매), 무장 화면의 장비 강화(+1마다 기본 능력치 10%, 최대 +10, 실패해도 등급 유지).
- **자동 전투**: 한 판을 끝까지 계산하며(속도가 빠른 쪽이 먼저), 합마다 대사·연출·양쪽 활력을 기록해 관찰하기로 다시 봅니다. 적의 공격은 회피 → (실패 시) 피격 → 반격 스탯 확률로 【반격】 순서로 판정하며, 회피에 성공하면 반격은 없습니다.
- **드랍** (`data/drops.js`): 요수마다 그 사냥터의 핵심 재료 6종 가운데 일부를 떨굽니다. 청풍산 — 야생 삼채 · 단단한 흑목 · 멧돼지 어금니 · 살쾡이 가죽 · 청령목 수액 · 거친 철광석 / 염화채 — 적염석 · 화염 전갈 독낭 · 늑대 힘줄 · 염화 대도 파편 · 적토 점토 · 정련된 흑철괴 / 수룡방 — 수로 백은광 · 악어 비늘 가죽 · 침묵의 수초 · 교룡 유체 비늘 · 독지네 다리 · 물안개 이슬. 두목은 돌파단 재료(영지버섯·화령초·혈삼·수련화)도 떨굽니다.
- **특수 전투 규칙**: 연격(흑풍채 척후병·적염 호랑이·적토 늑대·수룡방 강습대원·벽해룡, 두 번째부터 위력 60%), 중독(흑비단독사·독지네, 해독산으로 막음), 출혈·열상(화염 살모사·화포수·정예 도부수, 혈문도는 적에게 출혈), 요수 고유 약점(청령목괴 ← 화 기공, 염화석괴 ← 수 기공, 빙화수요 ← 토 기공), 그물 투망수의 높은 명중. 그 밖의 특성은 지문과 능력치로 표현합니다.
- **경계(2단계)**: 1~5성 입문(入門), 5→6성에 소성 돌파단을 더해 6성 소성(小成)(장착 능력치 30%·초식 위력 25% 상향), 11→12성에 대성 돌파단을 더해 12성 대성(大成 / 極意)에 이르고 분류별 극의 패시브가 열립니다.
- **연출**: 피해 숫자는 일반 적중이 주황·적색, 치명타가 1.5배 크기의 굵은 금색(떨림), 회피가 청록색 `회피!`로 솟구칩니다. 적중할 때마다 인장에 0.1초 섬광(적은 흰빛, 내가 맞으면 붉은빛)이 스치고, 치명타나 최대 활력 20% 이상의 강타에는 0.15초 잔떨림(`@keyframes shake`)이 붙습니다. 이 연출은 관찰하기 창에서 합마다 재생됩니다. 장문인·대사형·사매·왕 가의 첫 대사는 한 글자씩 찍히며, 아무 곳이나 누르면 전체가 바로 보입니다. 움직임 줄이기 설정에서는 모두 생략됩니다.

## 운영자 콘솔 (GM)
개발·테스트용입니다. 두 가지로 띄울 수 있고, 화면과 기능은 같습니다.

- **게임 안 오버레이**: 화면 우측 하단 `[GM]` 버튼이나 `F1` / `` ` `` / `~` 키로 여닫습니다(입력칸에 글자를 치는 중에는 `` ` ``·`~`를 무시). `Esc`나 바깥을 누르면 닫힙니다. 휴대폰 테스트에 편합니다.
- **별도 관리자 창 (`admin.html`)**: 오버레이 머리의 `[새 창 ↗]`을 누르거나, 게임과 같은 폴더의 `admin.html`을 직접 엽니다. 두 번째 모니터에 띄워 두고 게임하면서 보기 좋습니다.
  - 게임 창과 `BroadcastChannel`로 이어집니다. 게임이 1초마다 저장 상태 `S`와 전투 요약, 추적 기록을 보내고, 관리자 창은 [적용]·소환·재료 지급·치트를 **명령**으로 보내 게임 쪽에서 실행합니다.
  - 관리자 창은 `core.js`·`data/`·`systems/`만 읽어 받은 복사본으로 같은 계산(능력치 등)을 합니다. 화면 계층과 `app.js`는 읽지 않습니다.
  - 게임을 새로고침·초기화해도 관리자 창과 추적 기록은 남고 자동으로 다시 이어집니다. 게임 창이 없으면 머리에 '게임 창을 기다리는 중'이 뜹니다.
  - 같은 출처에서 열어야 합니다(같은 폴더·같은 사이트). 로컬 파일로 열 때 크롬 계열은 되지만, 파일마다 출처를 따로 보는 브라우저(파이어폭스 등)에서는 이어지지 않을 수 있습니다. 팝업이 막히면 `admin.html`을 직접 여십시오.

| 탭 | 기능 |
| --- | --- |
| 유저 상태 | 활력·내력·기력·은자·공헌도·수련치·탐험지·다음 출발, 장착 무공 4종의 ID·성·수련치, 행낭, 저장 상태 `S` 원시 JSON을 1초마다 갱신. 은자·활력·내력·기력·공헌도를 입력해 [적용] (최대치로 제한) |
| 행동 추적 | 탭 전환·화면 전환·클릭·전투 조우/승패·아이템 획득/소모·알림·경고(재화 부족 등)·예외를 밀리초 시각과 함께 기록. 최신이 위, 최대 300줄, 견문록과 별개, [로그 비우기] |
| 아이템 DB | 전체 아이템 표(ID·이름·분류·가치·보유), 검색·분류 거르기, [+1 소환] [+10 소환] |
| 조합법 | 레시피 48종의 재료·결과·도감 해금 여부, 기예별 거르기, [필요 재료 지급] |
| 쾌속 치트 | [은자 +1,000냥], [수련치 +1,000], [활력/내력 100% 회복], [기력 가득], [탐험 즉시 1회], [1시간 경과](예약된 탐험을 실제 결산 경로로), [10시간 경과](8번까지만 쌓이는지 확인), [데이터 완전 초기화](두 번 눌러 확인) |

- 값 주입은 기존 시스템 함수(`give`, `advance`, `clampVitals`, `doReset` …)를 그대로 불러 게임 상태·화면과 어긋나지 않습니다.
- 행동 추적은 시스템이 보내는 `notify.trace` 신호와 화면 계층의 신호(Bus)로 모읍니다. 시스템이 콘솔을 직접 알지 못하게 해 계층 규칙을 지킵니다.
- 출시할 때는 `js/ui/ui_admin.js` 맨 위의 `GM_ENABLED`를 `false`로 바꾸고(버튼·단축키·창 연결이 모두 꺼짐), `admin.html`을 배포에서 빼십시오.

```bash
cd gangho
npm install          # playwright 설치 (처음 한 번)
npm test             # 전체 검사, 실패가 있으면 종료 코드 1
node tests/run-all.js round10  # 이름에 round10이 들어간 묶음만
```
