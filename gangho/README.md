# 강호견문록 (江湖見聞錄) — 제1장 청풍문 편

텍스트 기반 무협 RPG 웹게임. 빌드 없이 `gangho/index.html`을 브라우저로 열면 바로 실행됩니다. 진행은 브라우저 `localStorage`에 저장됩니다.

## 구성
데이터·규칙·화면을 파일 단위로 나눴습니다. 한 기능을 고칠 때 다른 계층이 따라 깨지지 않게 하기 위해서입니다.

```text
index.html               화면 뼈대 + 스크립트 읽는 순서 (core → data → systems → ui → app)
css/
  main.css               전체 레이아웃, 탭, 패널·카드, 지도 격자
  combat.css             대치 패널, 전투 무대, 플로팅 대미지, 초식 현판
  effects.css            호버 발광, 셰이크, 섬광, 펄스, 수련 광원·기운 입자, 타자기, 현판·토스트
js/
  core.js                공용 도구(난수·수치·조사) + 이벤트 버스(Bus, notify)
  data/                  [SSOT] 순수 정적 데이터. 함수·반복문 없음
    martial_arts.js      비급, 등급·분류, 경계(입문/소성/대성), 관문, 대성 패시브, 실전 승리 수
    items.js             아이템·재료·소모품, 장비 기본형(티어별 능력치 표), 희귀도, 레시피 48종
    monsters.js          요수·두목 능력치와 고유 드랍 표, 피격 문구, 기척 지문
    maps.js              사냥터 배치 수량·요수 가중치, 금고 보상 풀, 함정, 구역, 기연 사건 표
    sect.js              조운 보급품·창고, 아린 대사
  systems/               게임 규칙과 계산. DOM 조작 금지, 화면 상태(ui) 참조 금지
    stats_engine.js      능력치 합산(장비·비급·무신상·버프)
    training_engine.js   연무장 수련 카운트업, 성 경험치, 관문·경계 돌파, 시간 흐름
    inventory_engine.js  행낭·무장·무공 장착, 소모 판정, 장비 강화
    combat_engine.js     3초 자동 전투, 명중·치명, 회피→반격 분기, 승패 정산
    explore_engine.js    사냥터 생성(BFS), 이동, 함정, 금고, 기연 사건
    craft_engine.js      화로 기예, 도감 단서, 무신상 봉헌
    sect_engine.js       문파 임무, 인물(조운·아린·장문인), 장경각, 창고, 하산
  ui/                    화면 출력과 입력 바인딩
    ui_tabs.js           화면 상태(ui), 탭 전환, 상단 상태줄, 정청 아코디언, 전체 다시 그리기
    ui_logger.js         견문록: 최신 기록을 위에 붙이는 역순 로그
    ui_feedback.js       성취 현판, 토스트, 플로팅 대미지, 섬광·셰이크, 타자기
    ui_views.js          정청·무공·연무장·화로·뒷마당·무장·무신상·도감 화면
    ui_field.js          강호행 지도와 전투 무대
    ui_modals.js         무공 상세·기연 사건·레시피·처음부터 다시·시작 화면 창
    ui_input.js          클릭·변경·키보드 → 시스템 함수 연결
  app.js                 초기화, 저장 상태 S와 런타임 상태 RT, 저장/불러오기, 저장 이전, 1초 틱
assets/                  무장 실루엣과 NPC 초상화. 없는 파일은 대체 그림으로 표시 (assets/README.md)
```

**계층 규칙**
- `data/`는 값만 담습니다. 레시피·비급서 아이템·장비 티어 능력치도 계산식 없이 표로 풀어 적었습니다.
- `systems/`는 상태 `S`·`RT`만 바꾸고, 화면에는 `notify.refresh()`·`notify.toast()`·`notify.banner()`·`notify.battle()`·`notify.view({ tab, modal, … })`·`notify.save()` 신호만 보냅니다. 화면 계층이 `Bus.on(...)`으로 받아 그립니다.
- `ui/`는 시스템 함수를 부르고 결과를 그립니다. 저장소에는 손대지 않습니다.
- `tests/check-layers.js`가 이 규칙을 정적으로 검사합니다: 데이터 파일의 로직, 시스템의 DOM 접근·화면 함수 호출·`ui` 참조, 스크립트 순서. `npm test`에 포함되어 있습니다.
- 모듈 번들러 없이 `file://`로 바로 열리도록 ES 모듈 대신 순서가 정해진 일반 스크립트를 씁니다.

## 구현된 시스템
- **탭 순서**: 정청 · 상태 · 연무장 · 화로 · 뒷마당 · 강호행 · 무신상 · 도감. 좁은 화면(640px 이하)에서는 1차 탭 8개가 4×2 격자로 모두 보여 가로 스크롤이 없습니다.
- **상태(狀態)**: 상단의 [ 무장 ] / [ 무공 ] 하위 탭으로 전환합니다. 무장은 착용 장비 슬롯과 행낭, 무공은 장착 중인 4대 무공·익힌 무공·보유 비급을 보여 줍니다. 마지막에 본 하위 탭을 기억합니다.
- **무공**: 시작하면 입문 무공 비급 1권과 토납법·포철삭·철포삼 비급이 행낭에 들어옵니다. 상태 › 무공(또는 상태 › 무장의 행낭)에서 [ 익히기 ]로 익히고, 상태 › 무공에서 무공·심법·경공·기공 슬롯에 장착하거나 해제합니다. 익힌 무공 카드를 누르면 등급, 성과 숙련도, 설명, 장착 보너스, 초식, 장착하기/장착 해제 버튼이 있는 창이 뜹니다. 장착한 무공만 연무장에서 수련할 수 있고, 장경각에서 교환한 비급도 행낭으로 들어옵니다.
- **견문록**: 넓은 화면에서는 왼쪽 본문과 같은 높이로 고정되고 최신 기록이 맨 위에 쌓입니다. 아이템명·은자·공헌도는 색으로 강조됩니다.
- **화면**: 먹빛 다크 테마입니다. UI·수치는 Noto Sans KR, 지문·전투 로그·대사는 Noto Serif KR로 씁니다. 메뉴 이름은 한글을 크게, 한자를 작게 붙입니다.
- **연무장**: 처음엔 수련 정지 상태입니다. 카드마다 [ 수련하기 ]/[ 수련 중지 ]가 있고, 한 번에 장착한 비급 하나(`activeTrainingSkillId`)만 수련 경험치가 쌓입니다. 오프라인 수련은 최대 24시간까지 쌓입니다.
- **무신상**: 독립 탭입니다. 기예 실패 부산물을 봉헌해 영구 능력치를 얻습니다.
- **화로**: 주조·연단·조리, 최대 10칸 투입. 모든 재료에 `craftType`(forge/alchemy/cooking)이 있어 고른 기예의 재료만 보이고, 레시피도 한 분류 재료로만 만듭니다. 성공률 대신 숙련에 따라 불길 지문이 바뀝니다. 레시피는 48종입니다.
- **뒷마당**: 평상 휴식(활력·내력은 항상, 기력은 5분 간격으로 전부 회복), 음식·영약 먹기, 아린(일일 약과, 이야기 나누기).
- **정청**: 노벽송(장문인)이 지금 할 일 하나만 순차로 알려 줍니다. 조운(대사형)은 하루 한 번 보급품을 줍니다. 문파 임무로 문파 공헌도를 벌고, 장경각에서 청풍문 세트(청풍권·검·도·창·표, 청풍심법·경공·기공, 신분패)와 바꿉니다.
- **상태 › 무장·행낭**: 중앙 실루엣 이미지 둘레에 투구·무기·호갑·옥패, 하단 가로줄에 신발·요대·가락지·신분패·탈것. 행낭 기본 100칸.
- **도감**: 레시피 해금 그리드. 조합에 성공하면 그 조합에 쓴 재료마다 '이 재료가 들어가는 다른 조합식'이 단서 칸으로 드러납니다. 단서 칸에는 완성품과 아는 재료만 보이고 나머지는 가려져 있어, 유저끼리 정보를 나누며 채워 가게 됩니다. 화로 제작에 성공하거나 아린·장문인에게 들으면 영구 해금됩니다. 해금된 칸을 누르면 완성품 능력치, 필요 재료, 화로 채우기 버튼이 있는 창이 뜹니다.
- **강호행**: 사냥터는 12×10 격자로 입장할 때마다 새로 생성됩니다. 입구는 좌측 하단, 두목은 우측 상단 끝이며 BFS로 모든 칸이 이어집니다. 보이는 산길은 약 50%이고, 요수(妖獸) 23~27, 금고(金庫) 19~23, 기연 1이 몰리지 않게 흩어져 있습니다(약초 군락·광맥은 금고로 통합). 요수 칸을 밟으면 지역 요수 중 하나가 가중치로 정해져(깊을수록 중형) 대치(對峙) 패널에 나타나고, 전투력 비교 지문(녹색·황금·적색)을 본 뒤 [ ⚔️ 결투 시작 ]을 눌러야 싸움이 시작됩니다. 금고를 열면 약재 궤(연단 재료)·철물 궤(주조 재료)·식재 궤(조리 재료)·은자 궤(15~35냥)·비급/장비 궤(희귀) 중 하나가 나옵니다. 숨은 함정 4~6개는 산길과 똑같이 보이다가 밟으면 발동하고 산길이 됩니다. 기연(奇緣) 칸 2~3곳을 밟으면 사건 창이 뜹니다. 지역마다 고유 사건 4종과 공용 2종(부상당한 약초꾼, 떠돌이 낭인, 포로가 된 상인, 강가의 노인 등) 중에서 한 사냥터 안에서는 겹치지 않게 나오고, 선택지(일부는 아이템·은자·기력·능력치·무공 성급 조건)에 따라 확률로 보상·손해·전투가 갈립니다.
- **강호행(공통)**: 청풍산 → 염화채 → 적룡방 순서로, 두목을 꺾으면 다음 지역이 열립니다. 지도는 시작할 때 BFS로 입구에서 모든 노드(두목 포함)까지 이어지는지 검사하고, 끊긴 곳은 산길로 잇습니다. 기믹은 길을 막지 않고 보상을 줍니다. 적 수치는 숨기고 기척 지문 5단계로 알려 줍니다. 자동 회복은 없습니다. 토벌·채집·채광·상자·기믹을 마친 노드는 산길이 되고, 청풍문에 돌아갔다 다시 들어가야 지도 전체가 재배치됩니다.
- **실전 경험치**: 전투 1회 승리마다 장착한 비급에 각각 +1.
- **은자 사용처**: 정청의 조운의 창고(소모품·재료 구매), 무장 화면의 장비 강화(+1마다 기본 능력치 10%, 최대 +10, 실패해도 등급 유지).
- **자동 전투**: 선택지 없이 3초마다 한 합(속도가 빠른 쪽이 먼저)씩 공방이 오가고, 전투 창과 견문록에 기록됩니다. 적의 공격은 회피 → (실패 시) 피격 → 반격 스탯 확률로 【반격】 순서로 판정하며, 회피에 성공하면 반격은 없습니다. 영약은 전투 중에도 쓸 수 있습니다.
- **드랍**: 적마다 고유 드랍 테이블만 판정합니다(들토끼: 토끼고기·토끼가죽, 들개: 들개 이빨·거친 가죽, 멧돼지: 멧돼지고기·송곳니·두꺼운 가죽, 외눈 멧돼지왕: 왕의 송곳니·흑철·불씨석).
- **경계(2단계)**: 1~5성 입문(入門)은 성당 수련 8시간·실전 10승, 5성이 차면 소성 관문에서 소성 돌파단을 복용해 6성 소성(小成)에 이릅니다(장착 능력치 30%·초식 위력 25% 상향). 6~11성은 성당 16시간·20승, 11성이 차면 대성 돌파단으로 12성 대성(大成 / 極意)에 이르고 분류별 극의 패시브가 열립니다.
- **연출**: 피해 숫자는 일반 적중이 주황·적색, 치명타가 1.5배 크기의 굵은 금색(떨림), 회피가 청록색 `회피!`로 솟구칩니다. 적중할 때마다 인장에 0.1초 섬광(적은 흰빛, 내가 맞으면 붉은빛)이 스치고, 치명타나 최대 활력 20% 이상의 강타에는 0.15초 잔떨림(`@keyframes shake`)이 붙습니다. 연무장의 수련 중인 비급 카드는 금빛·청록빛 광원이 숨 쉬듯 밝아졌다 어두워지고, 기운 입자와 아지랑이가 아래에서 피어오릅니다. 장문인·대사형·사매의 첫 대사와 기연 문구는 한 글자씩 찍히며, 아무 곳이나 누르면 전체가 바로 보입니다. 지도 칸에 마우스를 올리면 2px 떠오르며 요수는 붉은빛, 금고는 황금빛, 기관(채집지)은 초록빛으로 빛나고, 이동하면 도착 칸이 0.2초 튀어 오릅니다. 움직임 줄이기 설정에서는 모두 생략됩니다.

## 검사
브라우저 자동 검사(Playwright)가 `tests/`에 있습니다. 데스크톱(1280px)과 폰(390px) 폭에서 게임 규칙과 화면을 확인합니다.

```bash
cd gangho
npm install          # playwright 설치 (처음 한 번)
npm test             # 전체 검사, 실패가 있으면 종료 코드 1
node tests/run-all.js round10  # 이름에 round10이 들어간 묶음만
```
