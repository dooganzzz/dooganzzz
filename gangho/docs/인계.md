## 2. 배포 순서 (도구는 모두 저장소 안)
```bash
cd gangho
node tools/stamp.js                      # ?v= · version.json
python3 tools/bundle.py <scratchpad>     # → <scratchpad>/gangho.html, admin.html
node tools/bundle-check.js <scratchpad>  # 번들이 뜨는지 + GM 별도 창 연결
node tests/check-layers.js               # 계층 규칙
git add -A . && git commit && git push -u origin claude/gangho-web-game-7dlmy4
```
그다음 Artifact publish: `file_path=<scratchpad>/gangho.html`, `url=게임 아티팩트`, `files={"admin.html": "<scratchpad>/admin.html", 새 그림…, 지운 그림: null}`.
그림을 지웠으면 `node tools/assets-check.js`(안 쓰는 그림 찾기)도 돌린다. 이름을 이어 붙여 쓰는 그림(`'cv_' + 갈래`, `'map_' + 지역`, `_hz`)은 쓰는 것으로 센다.

## 3. 그림 · 연출 체계 (꼭 지킬 것)
- 그림 경로는 `js/data/assets.js` + `js/ui/ui_assets.js`(`ASSET.종류(이름)`)에서만.
- 무공 그림: `assets/art/common/`은 두루마리와 평타만, `assets/art/manual/<무공id>/`는 그 무공 것만 (`MANUAL_ART` 목록과 폴더가 같아야 함 — check-layers가 검사). 그림이 없는 초식 · 오의는 평타.
- 초식 그림 고르기는 `ui_sprite.js`의 `stanceFxSrc` 한 곳, 오의는 `ui_ougi.js`의 `ougiCfg`.
- 모든 무공 그림은 **시문 + 무공 이름**을 바탕으로 그린다 (`docs/시문.md`). 화풍 기준은 CLAUDE.md의 "강호 지도 2번".
- 연출 시간: `ui_callout.js` `CO_TL` · `CO_MOVE_AT`(두루마리 시계와 무공 시계는 따로 셈).
- 연출 미리보기 컷 뜨기 예시: `tools/cap-frames.js` (애니메이션을 멈추고 40ms씩 옮기며 찍기 → 10열 시트).
- 먹빛(검은) 그림은 `mix-blend-mode: screen`에서 지워진다. 유묵검법처럼 먹 그림을 넣을 때는 그 무공만 normal 겹치기로.

## 4. 최근 추가된 것
- **단조 강화**: 화로 › 단조 › 장비 탭. 같은 이름 · 같은 등급 · 같은 부위의 강화 안 된 장비(전방에서 산 것 제외)를 재료로 +1~+10.
  비용 하급 10/20/30냥(+1~3/+4~7/+8~10), 등급마다 ×2. 확률 `ENH_RULE`(items.js). 능력치 단계마다 +2.86%(`ENH_STEP`, +7 ≈ 한 등급 위), 5 이상 수치는 올림.
  연출은 `ui_furnace.js` `enhStage` + `css/art.css` "단조 강화 연출" (지난 시간 `--el`만큼 당겨 이어 재생).
  GM AI도 `aiEnhance`로 +7까지 강화(파괴 구간은 안 함, 은자 50냥 남김).
- GM 콘솔 '유저 상태' 탭 삭제(렉), 쾌속 치트의 초식 100%는 모든 무공에 적용(`S.gmMove`).

## 5. 유저가 아직 고르지 않은 것 (보기를 띄웠지만 닫힘)
지금도 유효한 것만 남겼다. 다시 물을 때는 AskUserQuestion(여러 개 선택)으로.
1. **유묵검법 시안 고르기** — 미리보기의 유묵검법 시안 9장(1초식 묵기 ①~③ · 2초식 철의명 ①~③ · 오의 호기점전적 ①~③) 중 확정본. 고르면 GPT Image 2.5로 1장씩 확정본 → 보여 주고 넣기.
2. **강화 다음 건의** — 강화 소리 · +N 이름 색 구분(+4↑ · +8↑) · 견문록에 '그대로'는 안 남기기 · +8↑ 파괴 방지 '보호 부적'.
3. **두루마리 위치 · 크기 조정** — 정보창 · 커진 PC 무대에 맞춰 미리보기에 PC · 모바일 슬라이더.
4. **견문록 글자 12px(PC)** · **모바일 무대 이름 글자(8px) 테두리 진하게**.
5. **보상을 연출 끝난 뒤 넣기** — 요수가 쓰러지는 순간 은자가 오르고 '+은자'가 뜨게 (자리 비움 땐 지금처럼 바로).
6. **두루마리 외침 범위** — 초식마다 매번 외치기 / 관찰 창(다시 보기)에도 외침 (지금은 관찰 창에 없음).
7. **겹침 검사 넓히기** — 팝업(관찰 창 · 각성 창 · 비급 상세 · 초식 외침)까지 `overlap-check.js`에 넣기, 장면 그림(무신상 · 가부좌 · 화로) 고르는 곳 하나로 묶기.
8. **연혼각** — 거울 8개로 다시 · 깜박임 더 또렷하게 · [엮기] 연출.
9. **좌선 테두리 게이지 확정본** — 시안 ④ 청동 틀 24칸 · ⑤ 연꽃 등잔 24개 · ⑥ 기운 불꽃 24호 (섞기 가능).
10. **밸런스** — 대성 돌파단 얻는 곳 하나 더(12성에 4개 필요, 지금 3개) · 토벌 지역 배율(+20%씩 → 예: +50%씩) · AI 7일 시뮬로 막힘 표.
11. **다른 초식도 시계 스크롤 미리보기에** · **효과음 시안**(초식 · 두루마리 · 오의).
12. **전체 검사(`npm test`)** — 유저가 요청할 때만. 마지막 전체 검사 뒤로 강화 · AI · 보상 구조가 바뀌었다.
