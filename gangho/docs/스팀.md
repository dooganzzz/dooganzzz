# 스팀판 (데스크톱판)

웹판과 **같은 게임 코드**를 Tauri 창에 띄운 것이다. 게임 규칙 · 화면 · 그림은 웹판을 고치면 함께 바뀐다.

## 웹판과 다른 점 (코드: `DESKTOP` — `js/ui/ui_assets.js`)
- 혼자 하는 게임: 로그인 화면 · 계정 서버(Supabase) · 전체 로그아웃 · 새 버전 확인 · 운영자(GM) 콘솔을 쓰지 않는다. 서버로 아무것도 보내지 않는다.
- 저장: 이 컴퓨터의 앱 저장소(웹 저장소, `%LOCALAPPDATA%\com.dooganzzz.gangho`)에 남는다.
- 소리: 브라우저처럼 첫 클릭을 기다리지 않아도 된다 (지금은 웹판과 같이 첫 클릭에 시작).

## 만들기
- 자동: GitHub에 올리면(push) Actions › **강호견문록 데스크톱판**이 윈도우 실행 파일을 만든다 (`.github/workflows/gangho-desktop.yml`).
  그 실행 화면 아래 Artifacts에서 `gangho-windows-exe`(스팀에 올릴 Gangho.exe) · `gangho-windows-setup`(시험 설치 파일)을 받는다. Actions 탭의 Run workflow로 직접 돌려도 된다.
- 손으로: `python3 gangho/tools/desktop-dist.py` → `cd gangho/desktop && npx @tauri-apps/cli@2 build`

## 아직 할 일
1. 저장을 파일(JSON)로 + 스팀 클라우드 (다른 PC에서 이어 하기)
2. 스팀 로그인 · 업적 (Steamworks — 스팀 개발자 계정이 생기면)
3. 시작할 때 소리 바로 켜기 · 전체 화면 단축키 · 창 크기 기억
4. 스팀 상점 그림(캡슐 · 스크린샷 · 아이콘) — 지금 아이콘은 제자 얼굴을 잘라 쓴 임시
5. 스팀 쪽 (유저가 직접): Steamworks 가입 · Steam Direct 등록비 $100 · 세금 정보 · 상점 페이지는 출시 2주 전에 공개
