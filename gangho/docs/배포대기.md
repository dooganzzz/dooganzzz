# 배포 대기 목록

> 유저가 배포하라고 할 때까지 모아 둔다 (CLAUDE.md '배포는 모아서'). 배포하면 비운다.

(마지막 배포: 철사장 확정본 + 새 무공 48종 + 시문 4줄 규칙, 10월 2일)

1. 전투력 공식 · 비급 · 장비 · 강화 · 드랍 리밸런싱
2. 전방 되팔기: 전방에서 파는 물건은 사들이는 값의 절반
3. 강호행 화면 정리: 위 시간 · '강호행 중' 표시 · 아래 카운트다운 · 설명 · 탐험지 칸 삭제
4. 돌파하기 버튼 (조건 충족 시 활성, 미달 시 조건 팝업) · 전리품 합산 표시
5. 상성 줄을 경공(지형) · 기공(오행)으로 나눠 설명
6. 화로: 단조 · 연단 · 연혼 화면 크기 통일, 단조는 한 화면에서 재료만 '조합 재료' / '장비 재료'로 나눔
7. 아이템 정렬: 등급 높은 순 → 같은 등급은 가나다순 (행낭 · 판매 · 장착 목록 · 재료 · 비급)
