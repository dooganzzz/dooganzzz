# 배포 대기 목록

> 유저가 배포하라고 할 때까지 모아 둔다 (CLAUDE.md '배포는 모아서'). 배포하면 비운다.

(마지막 배포: v202610030756 — 좌선 게이지 장착 무공 기준 · 요수가 칠 때 소리 · 검 타격음 고침 · 대사 도트음 ×4)
1. 대화 도트음은 말을 건 대화 창에서만 (인사말 · 접힌 칸에서 소리 안 남)
2. 단계 조건 승수를 채우면 그 자리에서 첫 돌파로 기록 · 보상 → 가르침 · 임무가 사냥터를 나가지 않아도 이어짐
3. 검 타격음을 유저가 보낸 새 소리로
4. 돌파 조건을 채우면 [돌파하기]에 빨간 점
5. 정청 머리 '가르침 보상' 글 없애고 빨간 점만 (접혔을 때 머리, 펼치면 받을 자리 · 토벌 보상 단추에도)
