# 배포 대기 목록

> 유저가 배포하라고 할 때까지 모아 둔다 (CLAUDE.md '배포는 모아서'). 배포하면 비운다.

(마지막 배포: v202610030235 — 별호 · 호패 · 문파 대화(아린 · 조운 · 장문인) · 자질 · 단련 개편 · 강호 지도 · 청풍문 전경 · 용어 정리 · 소리, 10월 3일)

1. 첫 화면(로그인)만 명첩 → 아이디 (조사 어긋남도 고침: 아이디는 · 아이디를 · 아이디로)
2. 첫 화면 [입문 등록] → [가입하기] · 맨 아래 안내 "처음이면 [가입하기]로 아이디를 만드세요."
3. 청풍문 갈래 메뉴 없앰 → 전경 그림의 구름 이름표(정청 · 화로 · 연무장 · 무신상 · 전방 · 산문)를 눌러서만 이동 (청풍문 탭 = 전경)
4. 전경 · 강호 지도 아래 설명 글 지움
5. 화로: '재료' 글씨 지움 · 단조 · 연단 재료 칸 자리 통일 · 단조 · 연단 설명의 '조합식은 알려져…' 문장 지움
6. 연혼: [연혼주입] · 명경 누르기 없앰 → 조각을 누르면 팔괘 거울에 한 장씩, 8장이 차면 단로가 켜지고 단로를 눌러 주입 · 설명의 '같은 등급 조각 8장…' 문장 지움
7. 용어: 회피율 → 회피 · 속성 '취약' → '약함' · 특화 → '○○에 능함' · 수련치 획득 → 정진
8. 관조: 세부 능력치는 눌러야 펼침 · 채비 · 성향 자리 옮김(무장 패널) · 투력을 호패 옆으로
9. 서장 성명: '(5자까지)' 지움 · 5자 넘기면 '성명은 최대 5자까지만 가능합니다.' 알림
10. 힉스 확정본(확인 대기): 구름 이름표 · 내단 4종 · 속기단 · 아이콘 12종 · 비표 · 발자국 3 · 꺼진 승급 고리
