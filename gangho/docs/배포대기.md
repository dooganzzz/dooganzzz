# 배포 대기 목록

> 유저가 배포하라고 할 때까지 모아 둔다 (CLAUDE.md '배포는 모아서'). 배포하면 비운다.

(마지막 배포: v202610030516 — 관조 새 배치 · 성향 새 규칙 · 소속 청풍문 · 행낭 다듬기 · 소리 다시 켬 · 최적화 외 21건)
1. 서장(캐릭터 만들기): 바깥 · 빈 곳을 눌러도 안 넘어감 — [호패 만들기] → 성명 [확인] → 능력치 [이대로 정한다] → 입문 무공 고르기 → 기예 · [강호 출도] (성명 확인 전엔 출도 안 됨)
2. 배경음악: 첫 화면에서 바로 틀어 봄 (브라우저가 막으면 첫 손길에 이어 틂)
3. 무장: 부위 이름을 네모칸 안쪽 6시로 · 장비 이름은 칸 아래 등급 색(빈 칸은 글씨 없음) · 장비 그림 살짝 위로
4. 구름 이름표 자리: 무신상 (27.5, 12.5) · 정청 (50, 9) · 화로 (73, 15.5) · 전방 (36.5, 33) · 연무장 (71, 59) · 산문 (50, 77.5)
5. 빈 칸 금빛 + : 무공 탭 비급 칸('비어 있음' 지우고 또렷하게) · 화로 재료 칸
6. 좌선 아래 글씨: '운기조식' 지우고 품계는 '삼류(三流)'만 + 고리 절반이면 '소주천(小周天)', 다 차면 '대주천(大周天)' (아이템 글씨체) — 크기 · 색 · 자리 슬라이더 값 대기
7. 돌파 단약 속기단 → 파관단(破關丹)
8. 장문인 빨간 점: 받을 사명이 있는데 안 받았으면 청풍문 탭 · 정청 구름 · 정청 본부 머리 · [가르침 청하기]에 점
9. 토벌 임무 칸: 장문인 아래 → 조운 대사형 바로 아래로
10. 청풍문 대화(인물 칸 · 대화 창): 한 글자씩(중간 빠르기) + 두 글자마다 도트음, 여러 줄은 차례로
11. 첫 사명 · 비급 안내: '관조 › 무공에서 익히기' → '행낭에서 [익히기] 후 관조 › 무공에 장착'
